# Feature history

Every feature by the release that introduced it, newest first. Back to the [documentation index](README.md).

> These are release notes. Later releases changed some of them; entries that no longer describe current behaviour carry a **⚠ Now:** note. Figures marked as measured on synthetic data come from the project's own generators, not from real users or real bots.

| Feature | Description |
| :--- | :--- |
| 🧪 **Measured corrections, replay defense and honest defaults (v0.11.0)** | Every change was measured before and after on the same seeds; human false-positive figures use the real SapiMouse dataset (120 people), bot figures are synthetic. **1D-CNN is `shadow` by default** (`SYNAPSE_CNN_MODE`): the bundled weights were trained on synthetic noise only and blocked ~19% of real human windows; the model no longer loads `./synapse_weights.npz` from the working directory (use `SYNAPSE_WEIGHTS_PATH`). **Short traces** (<40 pointer samples) can no longer be blocked by the straightness / FFT / sub-movement rules alone (real single movements blocked 50% → 4.9%); such gray-area sessions get a challenge even with proof-of-work off. **Replay defense:** a keyed 64-bit trajectory fingerprint blocks a recorded trace re-sent with a fresh token (1 h TTL, no raw trace stored), and a shape SimHash catches noisy / scaled / time-warped repeats within a session, also across User-Agent changes. **Fewer false blocks:** a `touch_supported` flag without touch events is reclassified as desktop instead of penalised (touch-screen laptops and iPads with a keyboard were blocked 71-100%); the 60 s device penalty is keyed by HMAC(IP + User-Agent); token errors no longer penalise the device; only hard violations or Bot verdicts with risk ≥ 85 count toward the 4-strike IP ban; Chrome's synthetic (0,0) click on Enter is ignored. **Client signals can only raise risk.** **SDKs:** each token carries only events inside its own challenge window; Vue `submitProtected()`; `input_events` (autofill / paste / IME counts, never content); SRI hash script. **Tooling:** PyO3 0.30 abi3 wheel (CPython 3.10-3.14), `doctor` fails on a stale native core, `logs.user_agent` follows `SYNAPSE_PRIVACY_MODE`. |
| ⌨️ **Keyboard-only access and React proof-of-work (v0.10.8)** | Keyboard-only sessions (screen readers, switch access, Tab navigation) are no longer hard-blocked on their own: +40 instead of +50, and the adapters send them a challenge even with `enable_pow` off (`SYNAPSE_KEYBOARD_ONLY_CHALLENGE=0` turns it off). React `submitProtected` / `solvePow`; vanilla solver cap 20M attempts. Measured on synthetic data: keyboard-only humans blocked 94% → 2.4%. |
| 🔭 **Shadow cohorts, rule codes and offline replay (v0.10.7)** | Per-cohort shadow counters (input class × devicePixelRatio), stable rule codes (`SynapseDecision.rule_codes`), `report_shadow_outcome()`, Grafana + Prometheus assets (`deploy/monitoring/`), `synapse-shield replay`. Stutter and fast-typing rules recalibrated on real human data (real 20 s windows blocked 2.7% → 0.5%). |
| 🧾 **Honest tooling and API contract (v0.10.7)** | `synapse-shield test` / `redteam` exit non-zero when the server is unreachable or a verdict is wrong; `doctor` works on a bare install; `POST /api/score` returns `decision` on every branch; Prometheus on `/metrics/prometheus`; raw traces are not stored unless `SYNAPSE_STORE_RAW_TELEMETRY=1`. |
| 🔬 **Curvature gating and false-positive fixes (v0.10.6)** | The "chaotic curvature" check only uses points where the cursor actually moves (both neighbouring steps ≥ 5 px). Unified keystroke frequency lower bound (`0 < key_interval_avg < 25 ms`); mobile tap isolation on the polynomial acceleration rule. |
| 🛡️ **Zero-PII keystroke shield and SPA lifecycle (v0.10.4)** | Client-side masking: only keys on a closed allow-list of named control keys (`Enter`, `ArrowLeft`, `Unidentified`, `F1`-`F24`, …) are sent by name; every printed character, emoji, ligature, IME word and sensitive field is masked. Single-use token lifecycle for SPAs, signed proof-of-work difficulty, telemetry shifting on retry, CIDR trusted proxies, CGNAT User-Agent session isolation. ⚠ **Now:** client-computed `is_freq_digraph` can only raise risk (v0.11.0). |
| 🔐 **Client network binding and token relay defense (v0.10.1)** | Challenges bound to the /24 (IPv4) or /64 (IPv6) subnet and the normalised User-Agent (`nonce.ts.bind_hash.sig`), defeating token relay and harvesting farms. `synapse-shield doctor`. |
| 📱 **Mobile SDK v2.0 and anti-emulator signals (v0.10.0)** | Tap hold time, passive gyroscope / accelerometer micro-tremor (`motion_variance`), WebGL GPU cross-check (`is_mobile_gpu_mismatch`), Android Gboard / IME support. |
| 🛡️ **Kinematic hardening and proof-of-work defense (v0.9.9)** | Constant touch radius trap, hard-violation veto on gray-area challenges, fuzzy trajectory replay detection, click-to-cursor alignment (≤ 50 px), secret-keyed threshold jitter (±5%), anti-poisoning limits for active learning. ⚠ **Now:** a spoofed `touch_supported` flag is reclassified rather than penalised +75 (v0.11.0). |
| ⚡ **Vectorised 1D-CNN, Rust L1 cache, Alpine musllinux (v0.9.8)** | NumPy-vectorised CNN inference, thread-local WAL SQLite with in-memory ban/session caches, Alpine Linux (`musllinux_1_2`) wheels, Brave farbling handling. |
| 🛡️ **Enterprise hardening and reverse-proxy support (v0.9.7)** | `X-Synapse-Token` header, `SYNAPSE_TRUSTED_PROXIES` (`CF-Connecting-IP` / `X-Forwarded-For`), shadow mode, gray-area proof-of-work, Django and Flask parity. |
| 🚀 **ASGI 3.0, Litestar and Sanic (v0.9.6)** | Litestar route guards (`synapse_guard`), Sanic decorator (`@shield_protect_sanic`), zero-dependency ASGI 3.0 middleware with replay-safe body reading and a 256 KB limit. |
| 🎯 **Built-in red-team orchestrator (v0.9.5)** | Modular attack battery (6 plugins) and `synapse-shield redteam`. |
| 📦 **PyO3 universal abi3 wheel (v0.9.5)** | One pre-built binary wheel per platform for Python 3.10+. |
| 📊 **Rust state telemetry (v0.9.5)** | `/metrics` and `synapse-shield telemetry` for the native nonce and IP-ban caches. |
| 🛡️ **Algorithmic DoS and Poisson stability (v0.9.3)** | Iterative Poisson terms with a k ≥ 30 cut-off instead of factorials; O(1) deque keystroke pairing; trusted proxies and IPv4-mapped IPv6 normalisation; `allow_pickle=False` and path validation for model weights. |
| 📐 **Differential curvature, keystroke entropy, zero-copy buffers (v0.9.2)** | Vectorised curvature κ(t) in Rust (AVX2), dwell / flight / digraph timing with 8-bin Shannon entropy, zero-copy NumPy → Rust buffers. |
| 📱 **Mobile capacitive touch biometrics (v0.9.0)** | Touch radius, radius variance and pressure; native Rust SIMD kinematic core via PyO3. |
| ⚡ **Benchmark suite (v0.7.9)** | `synapse-shield benchmark` profiles kinematics, CNN and end-to-end evaluation. Synthetic human generator with multi-bell sub-movements. Isolated weights and `--bootstrap` calibration. ⚠ **Now:** weights load only from `SYNAPSE_WEIGHTS_PATH` or the package (v0.11.0). |
| 🌊 **FFT tremor, sub-movements, session invariance, adversarial retraining (v0.7.8)** | Spectral purity of the velocity signal, Fitts's-law sub-movement decomposition, sliding-window session invariance, adversarial training data. |
| 🛡️ **Security hardening (v0.7.7)** | Stored-XSS defense, admin-authenticated WebSocket console, SSRF allow-list for webhooks, composite SQLite index for strike counting, expired-token recovery without bans, 150-event input bounds, poisoning-resistant fine-tuning. |
| 🔔 **Discord and Telegram webhooks (v0.7.6)** | Blocked threats and bans forwarded from a background task. |
| ⚡ **Distributed state and Redis (v0.7.5)** | `SYNAPSE_REDIS_URL`: shared nonces (`SET NX EX`), strikes and bans with SQLite fallback. |
| 🧩 **Proof-of-work, iframe unhooking, SDK immutability, passive listeners (v0.7.2)** | Client-side SHA-256 puzzle that yields to the UI, clean prototypes from a hidden iframe, `Object.freeze` on SDK state, passive touch listeners. |
| 🪟 **Sliding-window IP ban** | 60-second sliding window, so injecting human-looking requests cannot reset a bot streak. |
| 🤖 **NumPy 1D-CNN and active learning** | 15 KB NumPy CNN over a 5-D movement sequence and an 8-D keystroke / scroll vector; `synapse-shield retrain` fine-tunes the last layers from SQLite logs. ⚠ **Now:** shadow by default (v0.11.0). |
| 🛡️ **Max gating fusion** | Heuristic rules and the CNN score were combined by taking the maximum. ⚠ **Now:** with the CNN in shadow mode only the heuristic rules decide unless `SYNAPSE_CNN_MODE=enforce`. |
| 🕵️ **Anti-stealth and tamper detection** | `navigator.webdriver`, fake plugin arrays, native `toString` overwrites in WebGL / Canvas. |
| ⚛️ **React, Next.js, Vue 3, Nuxt 3** | `synapse-shield-react` and `synapse-shield-vue` with hooks / composables and `<SynapseProtect />`. |
| 🐍 **Django and Flask adapters** | `SynapseShieldMiddleware`, `@shield_protect_flask`. |
| ♿ **Accessibility mode** | `accessibility_mode=True` scales kinematic risk down for motor-impaired and assistive-device users. |
| 📈 **Prometheus metrics** | Multi-process support via `PROMETHEUS_MULTIPROC_DIR`. |
| 🔐 **Single-use HMAC challenges** | Every session is bound to a single-use HMAC-SHA256 nonce; captured tokens cannot be replayed. |
| 🧱 **Body size limits** | 256 KB / 512 KB request body limits enforced while reading the stream. |
| 🔑 **Admin API protection** | `/api/clear` and other admin endpoints need `SYNAPSE_ADMIN_SECRET`. |
